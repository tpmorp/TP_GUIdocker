# AviUtl2 自由レイアウトプラグイン — 作成計画

## 背景
AviUtl2（導入済み 2.1.12、データフォルダ `C:\ProgramData\aviutl2`）の標準画面は、固定5区画にパネルを置く仕組み。区画の数・分け方は変えられない。
After Effects 同等以上に自由な画面構成を実現したい。

調査の結果、条件を満たすプラグインは存在しない。
- 旧AviUtl向けには、SplitWindow・アルティメットプラグイン「ワークスペース化」・AviUtlDock・UniteWindow がある。いずれも AviUtl2 非対応。
- AviUtl2 向けには該当品なし。導入済みの al2_* 群は見た目の調整のみ。

よって自作する（C++）。

## 方式（決定済み）
本体の各パネルを固定区画から取り外し、プラグインが用意する自由分割画面へ移し替える方式。
加えて、異常検知時は自動で本体標準の画面へ戻す「安全装置」を必須機能とする。

- 公式の手段は、自作パネルを本体へ組み込む `register_window_client` のみ。
- 本体パネルの取り外し・付け替えは、Windows の窓操作（親ウィンドウ変更・メッセージ横取り）で行う。

## 機能仕様草案
After Effects で多い不満への対策を含む。

1. **自由分割**
   - 縦横に何段でも分割可能。
   - 境界線はドラッグで調整。
   - 各パネルに最小サイズ、固定幅を指定可能。
2. **ドッキング**
   - パネルのタブをつかんで移動すると、落とし先（上下左右・タブとして重ねる）を大きく明示表示する。
   - 対策：AE の「落とし先が小さく分かりにくい」不満。
3. **メニューからの再ドッキング**
   - 右クリックメニュー「〜の隣へ移動」「元の位置へ戻す」。
   - 対策：AE はドラッグ以外で戻せない。
4. **ワークスペース**
   - 名前を付けて保存、ショートカットで切り替え、保存時の状態へリセット。
   - 明示的に保存するまで配置は一切変化しない。
   - 対策：AE の「勝手に配置が崩れる」不満。
5. **レイアウトロック**
   - 誤操作によるパネル移動・取り外しを防ぐ。
   - 対策：AE で要望の多い機能。
6. **パネル最大化**
   - AE の ` キー相当。1枚を一時的に全面表示する。
7. **表示の細部調整**
   - タブの高さ、余白、境界線の太さ、見出しの非表示、配色。
   - 導入済みのダーク化系と共存させる。
8. **独立ウィンドウ化**
   - パネルを別ウィンドウとして切り離す。マルチモニタに対応。
9. **安全装置**
   - 本体のバージョンが未検証の場合や、パネル取得に失敗した場合は、機能を停止して標準画面のまま起動する。
   - 本体の `aviutl2.ini` は書き換えず、設定は独自ファイルへ保存する。

## 段階計画
- **段階0 技術検証**（最重要）
  - 本体パネルの一覧取得。
  - 付け替え後に、描画・操作・サイズ変更が正常か確認。
  - 本体の区画処理と競合しないか確認。
  - 結果次第で仕様を再調整する。
- **段階1** 分割画面・境界線・設定保存・安全装置
- **段階2** ドッキング・タブ・落とし先表示・メニュー再ドッキング
- **段階3** ワークスペース・ロック・最大化・ショートカット
- **段階4** 表示細部調整・独立ウィンドウ化

## 確認方法
- 各段階で `.aux2` を `C:\ProgramData\aviutl2\Plugin` に配置して起動し、次を手動で確認する。
  - 分割・ドッキング・保存・再起動後の復元。
  - 意図的な失敗時に標準画面へ戻ること。
- 本体の ini は、作業前にバックアップを取る。

## 確定済みの細部仕様（2026-10-06）
- 初期配置：AE 風（左に素材系、中央プレビュー、右に設定、下にタイムライン）。
- パネル移動：タブをつかんでドラッグ。
- ワークスペース切替：ショートカットキー（変更可能）と画面上部の切替ボタン。
- 同種パネルの複数表示：不要（本体が元々複数持てるパネルはそのまま複数配置可）。
- レイアウトロック：前回終了時の状態を引き継ぐ。
- 開発環境：Visual Studio 2026 Build Tools（MSVC 14.50）。
